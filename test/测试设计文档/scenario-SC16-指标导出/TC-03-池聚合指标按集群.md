# TC-03 池聚合指标按集群

| 项 | 内容 |
|---|---|
| 用例编号 / 名称 | TC-03 / 池聚合指标按集群 |
| 所属场景 | SC16 指标导出 |
| 版本 | v0.1 |

## 测试目的

验证 per-cell 池聚合刷盘循环被接通：`llm_d_epp_ready_endpoints` 一旦 cell 的池绑定即产出（按集群区分）；同时验证"无新鲜端点时 `average_*` / `std_dev_*` 不产出"的既定语义，避免把缺失误判为 0 值。

## 运行模式

本地配置文件模式（`common.NewLocalEnv`）：不启动 inference-sim，端点不可达 → 端点指标不新鲜。以 `-pool-metrics-flush-interval=200ms` 加速刷盘。

## 前置条件

1. harness 已构建 epp 二进制。
2. 本地配置含两个已分配 cluster（cluster-a、cluster-b），各 1 个端点。
3. epp 已启动并就绪。

## 测试步骤

| # | 操作 | 预期 |
|---|---|---|
| 1 | 抓取 `/metrics`，检查 `llm_d_epp_ready_endpoints` | 20s 内 `{name="cluster-a"}` 与 `{name="cluster-b"}` 均出现（每集群一条） |
| 2 | 检查取值 | 均为 0（本地模式端点指标不新鲜） |
| 3 | 检查 `llm_d_epp_average_*` / `llm_d_epp_std_dev_*` | 六个家族**均不出现**（`podCount == 0` 提前返回，不导出误导性的 0） |

## 预期结果

- `ready_endpoints` 按集群产出且为 0；聚合家族按语义缺席。
- 刷盘循环随 cell 生命周期运行，无 panic / 泄漏。

## 清理

`defer e.Close()`：Kill epp 进程并 Wait；`t.TempDir` 自动清理。
